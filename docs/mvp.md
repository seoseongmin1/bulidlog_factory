# 공장 에너지 에이전트 MVP

> **MVP(최소 기능 제품)란?** 처음부터 모든 기능을 만들지 않고, 핵심 아이디어가 통하는지 확인할 수 있는 가장 작은 제품입니다. 자동차를 만들기 전에 먼저 굴러가는 킥보드를 만들어 보는 것과 비슷합니다.

## 1. 한 줄 소개

공장의 전기 사용 기록을 AI에게 말로 물어보면, AI가 직접 분석해서 그래프와 함께 쉽게 설명해 주는 앱입니다.

## 2. 왜 만드나요?

공장은 전기를 아주 많이 쓰지만, 사용 기록을 읽고 이해하는 일은 쉽지 않습니다.

- **데이터가 너무 많습니다.** 15분마다 기록이 쌓이면 1년에 3만 5천 줄이 넘습니다.
- **이상을 놓치기 쉽습니다.** 쉬는 날 전기를 평소보다 많이 써도, 표만 봐서는 눈에 띄지 않습니다.
- **보고서 작성에 손이 많이 갑니다.** 담당자가 숫자를 모으고 계산해서 정리해야 합니다.

이 앱은 이런 일을 자동으로 처리해서, 담당자가 **숫자를 찾는 시간을 줄이고 무엇을 할지 판단하는 데 집중**하도록 돕습니다.

## 3. 누가 쓰나요?

- **공장의 에너지 담당자, 생산관리자:** 전기 사용 현황을 확인하고 보고합니다.
- **공모전 심사위원, 채용 담당자:** 이 프로젝트의 1차 관람객입니다. 현재는 실제 공장 납품이 아닌 포트폴리오와 공모전이 목적입니다.

## 4. 어떤 데이터를 쓰나요?

전라남도 광양의 철강 공장인 대우스틸에서 2018년 1년 동안 실제로 측정한 전력 데이터를 씁니다.

| 항목 | 내용 |
|---|---|
| 측정 간격 | 15분마다 1번 |
| 데이터 양 | 35,040건 |
| 들어 있는 정보 | 전기 사용량, 역률, 이산화탄소 배출량, 부하 수준 |
| 없는 정보 | 기계별 사용량, 생산량, 제품 종류, 날씨, 전기요금 |
| 공개 출처 | UCI 머신러닝 저장소 (출처를 밝히면 사용 가능) |

처음에는 제조 AI 데이터 플랫폼인 KAMP의 불량 데이터를 후보로 생각했습니다. 하지만 가입 절차와 이용 조건을 확인하지 못해, 바로 받을 수 있고 이용 조건이 명확하며 실제 측정값인 이 데이터를 골랐습니다. 그래서 주제도 불량 분석에서 **에너지 분석**으로 바뀌었습니다.

## 5. 핵심 기능 4가지

### ① 한눈에 보는 대시보드

1년 치 전기 사용량을 숫자 카드와 그래프로 보여 줍니다. 월별, 시간대별, 날짜별로 언제 전기를 많이 썼는지 바로 알 수 있습니다.

### ② 이상한 날 찾기

앞뒤 4주 동안의 비슷한 날(평일은 평일끼리, 주말은 주말끼리)과 비교해서 유난히 많이 쓰거나 적게 쓴 날을 찾습니다. 추석처럼 공휴일이라 사용량이 적은 날은 공휴일 이름도 함께 표시합니다.

### ③ 일일 보고서 자동 생성

날짜만 고르면 그날의 사용량, 평소 대비 차이, 최대 사용 시각 등을 표로 정리해 줍니다. 파일로 저장할 수도 있습니다.

### ④ 말로 묻는 AI 에이전트

"1월과 9월을 비교해줘"처럼 평소 말투로 물어보면 AI가 필요한 분석을 골라 실행하고, 그래프와 함께 답합니다.

> **AI 에이전트란?** 질문에 답만 하는 챗봇과 달리, 목표를 이루기 위해 스스로 필요한 도구를 골라 쓰는 AI입니다. 사람이 "이 표 계산해 줘"라고 하나하나 시키지 않아도 됩니다.

## 6. 어떻게 작동하나요?

식당에 비유하면 AI는 **주문을 받고 음식을 설명하는 직원**이고, 분석 프로그램은 **정해진 레시피대로 요리하는 주방**입니다.

1. 사용자가 질문합니다.
2. AI가 어떤 분석이 필요한지 판단합니다.
3. 분석 프로그램이 데이터로 정확한 숫자를 계산합니다.
4. 앱이 계산 결과로 그래프를 그립니다.
5. AI가 결과의 의미를 쉬운 말로 설명합니다.

### 믿을 수 있게 만든 장치

- **숫자는 프로그램이 계산합니다.** AI가 숫자를 지어낼 위험을 줄이기 위해 계산은 프로그램이 맡고, 그래프도 계산 결과로만 그립니다.
- **사실과 추측을 나눕니다.** 기계별 데이터가 없어 정확한 원인은 알 수 없으므로, AI는 "가능성"이라고 표시하고 확인 방법을 제안하도록 지시했습니다.
- **모르는 금액은 말하지 않습니다.** 전기요금 정보가 없어서 원화 금액은 제시하지 않도록 했습니다.

### 만드는 방식

앞의 식당 비유로 보면 세 부분으로 나뉩니다.

| 부분 | 기술 | 식당에서의 역할 |
|---|---|---|
| 화면 | React | 손님이 앉아서 메뉴와 음식을 보는 홀 |
| 서버 | FastAPI | 정해진 레시피대로 계산하는 주방 |
| 데이터베이스 | Supabase | 전력 데이터를 보관하는 재료 창고 |

개발 중과 자동 테스트에서는 재료 창고로 내 컴퓨터의 SQLite 파일을 대신 씁니다. 시연할 때 Supabase로 바꿉니다.

## 7. 데이터에서 발견한 내용

| 발견 | 쉬운 설명 |
|---|---|
| 1년 총 사용량 959.6MWh | 공장이 2018년 한 해 동안 쓴 전체 전기량입니다. |
| 12월 16일 일요일 사용량이 평소의 약 5.5배 | 쉬는 날인데 큰 설비가 돌아갔을 가능성이 있어 확인해 볼 만합니다. |
| 새벽 4~6시 역률이 63%대 | 역률은 들어온 전기를 실제 일에 쓰는 비율입니다. 이 시간대는 효율이 낮습니다. |
| 최대 사용량을 10% 낮추려면 136.8kWh 이동 필요 | 사용량이 몰린 시간의 전기 사용을 다른 시간대로 옮길 때 필요한 양입니다. 공장의 작업 조건은 뺀 단순 계산입니다. |

### 데이터 오류도 찾아 고쳤습니다

원본 데이터는 매일 마지막 15분(23:45~24:00)을 그날의 `00:00`으로 기록하고 있었습니다. 그대로 시간순으로 정렬하면 **밤 기록이 그날 새벽으로 잘못 옮겨 갑니다.** 그래서 파일의 줄 순서를 기준으로 시간을 다시 계산했습니다.

## 8. 이번 MVP에서 하지 않는 것

작게 시작하기 위해 아래 기능은 뺐습니다.

| 제외 기능 | 이유 |
|---|---|
| 공장 설비와 실시간 연결 | 실제 공장이 없고, 공개된 과거 데이터로 먼저 검증합니다. |
| AI가 기계를 직접 제어 | 잘못되면 위험하므로 읽고 분석하는 일만 합니다. |
| 전기요금 계산 | 요금 데이터가 없어 금액을 만들어 낼 수 없습니다. |
| 기계별 원인 확정 | 기계별 데이터가 없습니다. |
| 로그인, 대화 기록 저장 | 내 컴퓨터에서 시연하는 용도라 지금은 필요 없습니다. |
| 다른 공장 데이터 업로드 | 한 공장의 데이터로 핵심 기능부터 검증합니다. |

## 9. 현재 진행 상황

| 항목 | 상태 |
|---|---|
| 대시보드 | 완료 |
| 이상한 날 찾기 | 완료 |
| 일일 보고서 | 완료 |
| 자동 테스트 27개 | 모두 통과 |
| AI 화면 흐름 | 가짜 AI 서버로 확인 완료 |
| **실제 AI와의 대화** | **미확인. API 키 필요** |

위 상태는 기본 웹 기술로 만든 시제품 기준입니다. 화면을 React로 다시 만들고 전력 데이터를 데이터베이스로 옮기는 작업은 아직 하지 않았습니다.

> **API 키란?** 앱이 AI 서비스를 쓸 수 있게 해 주는 비밀 열쇠입니다. 사용한 만큼 요금이 나오므로 다른 사람에게 공개하면 안 됩니다.

## 10. 성공 기준

아래 항목을 모두 만족하면 MVP가 성공했다고 판단합니다.

1. 추천 질문 4개에 AI가 실제 데이터 기반으로 답한다.
2. AI가 말한 숫자가 도구의 계산 결과와 일치한다.
3. AI가 원인을 단정하지 않고 사실과 가능성을 구분한다.
4. 처음 보는 사람이 설명 없이 3분 안에 질문하고 결과를 이해한다.
5. 공모전 발표에서 3분 안에 문제, 해결 방법, 발견한 내용을 시연할 수 있다.

## 11. 다음 할 일

1. API 키를 발급받아 실제 AI 대화를 시험합니다.
2. 추천 질문 4개의 답변을 확인하고 필요하면 AI 지시문을 고칩니다.
3. 화면을 React로 다시 만들고, 전력 데이터를 데이터베이스(Supabase)로 옮깁니다.
4. 주변 사람에게 사용해 보게 하고 어려운 부분을 고칩니다.
5. 시연 영상과 발표 자료를 만듭니다.
6. 온라인에 공개한다면, 그 전에 로그인과 사용량 제한을 추가합니다.

## 12. 용어 정리

| 용어 | 뜻 |
|---|---|
| 대시보드 | 중요한 숫자와 그래프를 한 화면에 모은 현황판 |
| kWh, MWh | 전기 사용량 단위. 1MWh는 1,000kWh |
| kW | 특정 순간에 쓰는 전기의 세기 |
| 최대 수요전력 | 일정 시간 동안 전기를 가장 세게 쓴 값. 이 앱에서는 15분 단위로 계산 |
| 역률 | 공급된 전기 중 실제 일에 쓰인 비율. 높을수록 효율적 |
| 부하 | 공장이 전기를 쓰는 정도. 경부하, 중부하, 최대부하로 구분 |
| 기준선 | 비교의 기준이 되는 평소 사용량 |
| 포트폴리오 | 내 실력을 보여 주기 위해 모아 둔 작업물 |
| 서버 (FastAPI) | 데이터를 계산하고 AI와 연결하는 프로그램 |
| React | 화면을 만드는 도구 |
| 데이터베이스 | 데이터를 정리해서 보관하는 창고 |
| Supabase | 인터넷에 데이터베이스를 두고 쓸 수 있게 해 주는 서비스 |
| SQLite | 내 컴퓨터의 파일 하나로 쓰는 작은 데이터베이스. 개발과 테스트에 씁니다. |
