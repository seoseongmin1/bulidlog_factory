# 기능 동작 설명서

[PRD.md](PRD.md)의 기능 4개가 사용자에게 어떻게 동작해야 하는지 정리한 문서입니다. PRD로 판단할 수 없던 내용은 확인을 거쳐 반영했습니다.

## 1. 모든 기능의 공통 조건

| 항목 | 내용 |
|---|---|
| 사용 환경 | 내 컴퓨터에서만 시연합니다. 온라인에 공개하지 않습니다. |
| 로그인 | 없습니다. 그래서 사용자별 권한 구분도 없습니다. |
| 볼 수 있는 사람 | 시연하는 컴퓨터의 화면을 보는 사람 |
| 원본 데이터 | 2018년 대우스틸 광양 공장 데이터 한 가지만 씁니다. 다른 데이터를 올릴 수 없습니다. 이 데이터는 데이터베이스에 들어 있고 앱은 읽기만 합니다. |
| 보관되는 것 | 사용자의 질문, 대화, 보고서, 접속 정보는 데이터베이스에 저장하지 않습니다. 저장한 보고서 파일은 사용자의 컴퓨터에만 있습니다. |
| 수정·삭제 | 앱 안에서 원본 데이터를 수정하거나 삭제할 수 없습니다. |
| 데이터 불러오기 실패 | 실패한 영역에만 안내문과 다시 시도 버튼을 보여 줍니다. 다른 기능은 계속 쓸 수 있습니다. 데이터베이스에 연결하지 못하는 경우도 여기에 포함합니다. |

## 2. 기능 1: 한눈에 보는 대시보드

### 사용자가 하는 일

- 입력할 항목은 없습니다.
- 앱을 열어 숫자 카드와 그래프를 봅니다.

### 정상 결과

- **저장:** 새로 저장되는 것은 없습니다.
- **화면:** 1년 치 사용량을 보여 주는 숫자 카드, 월별 그래프, 시간대별 그래프, 날짜별 그래프가 보입니다.

### 실패했을 때

- 입력이 없으므로 잘못 입력하는 경우는 없습니다.
- 데이터를 불러오지 못하면 대시보드 영역에 안내문과 다시 시도 버튼이 보입니다.

### 보기와 수정·삭제

- 시연 컴퓨터의 화면을 보는 사람은 누구나 볼 수 있습니다.
- 내용을 수정하거나 삭제할 수 없습니다.

### 제대로 만들었는지 확인하는 방법

- [ ] 앱을 열면 입력 없이 숫자 카드와 그래프 3개가 보인다.
- [ ] 1년 총 사용량이 959.6MWh로 표시된다.
- [ ] 월별 그래프에 1월부터 12월까지 12개월이 모두 있다.
- [ ] 날짜별 그래프에 1월 1일부터 12월 31일까지 이어져 있다.
- [ ] 불러오기에 실패하면 대시보드 영역에 안내문과 다시 시도 버튼이 보이고, 다른 기능은 계속 쓸 수 있다.

## 3. 기능 2: 이상한 날 찾기

### 사용자가 하는 일

- 입력할 항목은 없습니다.
- 화면의 이상한 날 목록을 봅니다.
- 목록의 날짜를 누르면 그날의 일일 보고서가 열립니다.

### 정상 결과

- **저장:** 새로 저장되는 것은 없습니다.
- **화면:** 탐지된 날 중 상위 8일이 이상 점수가 큰 순서로 보입니다. 날마다 사용량이 많은지 적은지 표시하고, 공휴일이면 공휴일 이름도 함께 보여 줍니다.

### 실패했을 때

- 입력이 없으므로 잘못 입력하는 경우는 없습니다.
- 데이터를 불러오지 못하면 이상한 날 목록 영역에 안내문과 다시 시도 버튼이 보입니다.

### 보기와 수정·삭제

- 시연 컴퓨터의 화면을 보는 사람은 누구나 볼 수 있습니다.
- 목록을 수정하거나 삭제할 수 없습니다.

### 제대로 만들었는지 확인하는 방법

- [ ] 목록에 정확히 8일이 보인다.
- [ ] 1위는 사용량이 많은 2018년 12월 16일이다.
- [ ] 2018년 1월 1일은 사용량이 적은 날로 보이고 공휴일 이름이 신정으로 표시된다.
- [ ] 평일은 평일끼리, 주말은 주말끼리 앞뒤 4주와 비교한 결과다.
- [ ] 목록의 날짜를 누르면 그날의 일일 보고서가 보인다.

## 4. 기능 3: 일일 보고서 자동 생성

### 사용자가 하는 일

| 행동 | 조건 |
|---|---|
| 날짜 선택 | 2018년 1월 1일부터 12월 31일까지 고를 수 있습니다. 처음에는 2018년 12월 16일의 보고서가 보입니다. |
| 저장 버튼 누르기 | 선택 사항입니다. 보고서가 화면에 보일 때 누릅니다. |

### 정상 결과

- **날짜를 고르면:** 새로 저장되는 것은 없습니다. 그날의 사용량, 평소 대비 차이, 최대 사용 시각 등이 표로 보입니다.
- **저장 버튼을 누르면:** 보고서가 브라우저의 다운로드 폴더에 `.md` 파일 1개로 저장됩니다. 파일 이름은 `energy-report-2018-12-16.md`처럼 날짜를 넣어 만듭니다.

### 실패했을 때

- 범위를 벗어난 날짜를 직접 입력하면 고를 수 있는 기간을 안내문으로 알려 줍니다.
- 보고서를 만들지 못하면 보고서 영역에 안내문과 다시 시도 버튼이 보입니다.
- 파일 저장에 실패하면 보고서 영역에 안내문과 다시 시도 버튼이 보입니다.

### 보기와 수정·삭제

- 화면의 보고서는 시연 컴퓨터의 화면을 보는 사람이 볼 수 있고, 앱에서 수정하거나 삭제할 수 없습니다.
- 저장한 파일은 앱 밖의 파일이므로, 그 컴퓨터를 쓰는 사람이 보거나 수정·삭제할 수 있습니다.

### 제대로 만들었는지 확인하는 방법

- [ ] 앱을 열면 2018년 12월 16일의 보고서가 보인다.
- [ ] 2018년 12월 16일의 보고서에 사용량 2,014.66kWh, 평소 대비 +450%가 보인다.
- [ ] 2019년 1월 1일처럼 범위 밖 날짜를 입력하면 고를 수 있는 기간이 안내된다.
- [ ] 다른 날짜로 바꾸면 표 내용도 그 날짜로 바뀐다.
- [ ] 저장 버튼을 누르면 다운로드 폴더에 선택한 날짜가 이름에 들어간 `.md` 파일이 생긴다.
- [ ] 저장한 파일을 열면 화면의 보고서와 내용이 같다.

## 5. 기능 4: 말로 묻는 AI 에이전트

### 사용자가 하는 일

| 행동 | 조건 |
|---|---|
| 질문 입력 후 보내기 | 평소 말투로 입력합니다. 내용이 있어야 하고 최대 2,000자입니다. |
| 추천 질문 누르기 | 선택 사항입니다. PRD에서 정한 4개 중 하나를 고릅니다. |

### 정상 결과

- **저장:** 대화 기록을 저장하지 않습니다. 화면을 새로고침하거나 창을 닫으면 대화가 사라집니다.
- **화면:** 분석 진행 상황이 보이고, 이어서 그래프와 AI의 설명이 보입니다.
- **답변 원칙:** 숫자는 분석 프로그램의 계산 결과를 씁니다. 사실과 추측을 나누고, 원화 금액은 제시하지 않습니다.
- **이어서 묻기:** 화면이 열려 있는 동안에는 이전 질문에 이어서 물을 수 있습니다.

### 실패했을 때

- 빈 질문은 보내지지 않고 화면도 바뀌지 않습니다.
- 2,000자를 넘게 입력할 수 없습니다.
- 데이터로 답할 수 없는 질문을 받으면 AI가 이유를 설명하고 답할 수 있는 범위를 알려 줍니다. 숫자를 지어내지 않습니다.
- AI에 연결하지 못하거나 API 키가 없으면 대화 영역에 이유를 안내합니다. 사용자는 질문을 다시 보낼 수 있고, 대시보드와 보고서는 계속 쓸 수 있습니다.

### 보기와 수정·삭제

- 대화는 시연 컴퓨터의 화면을 보는 사람이 볼 수 있습니다.
- 보낸 질문이나 받은 답변을 수정하는 기능은 없습니다.
- 대화 기록을 저장하지 않으므로 별도로 삭제할 기록도 없습니다.

### 제대로 만들었는지 확인하는 방법

- [ ] 빈 칸으로 보내기를 눌러도 질문이 보내지지 않는다.
- [ ] 2,000자를 넘게 입력할 수 없다.
- [ ] 추천 질문 4개를 누르면 각각 실제 데이터를 바탕으로 답한다.
- [ ] 답변 뒤에 "그것도 자세히 알려줘"라고 물으면 앞의 대화를 이어서 답한다.
- [ ] 새로고침하면 대화가 사라지고 이전 내용을 이어 가지 않는다.
- [ ] 답변의 숫자가 분석 프로그램의 계산 결과와 같다.
- [ ] 그래프의 값이 분석 프로그램의 계산 결과와 같다.
- [ ] 12월 16일의 사용량이 많은 이유를 물으면 원인을 단정하지 않고 가능성과 확인 방법을 말한다.
- [ ] "2019년 사용량은?"이나 "점심 메뉴 추천해줘"라고 물으면 이유와 답할 수 있는 범위를 알려 주고 숫자를 지어내지 않는다.
- [ ] API 키 없이 질문하면 대화 영역에 이유가 보이고, 대시보드와 보고서는 계속 쓸 수 있다.
- [ ] 비용을 물어도 원화 금액을 제시하지 않는다.
- [ ] 기계를 제어하라고 요청해도 제어하지 않는다.

## 6. 기능별 비교

| 기능 | 사용자 입력 | 저장되는 것 | 앱에서 수정·삭제 |
|---|---|---|---|
| 대시보드 | 없음 | 없음 | 불가 |
| 이상한 날 찾기 | 목록의 날짜 누르기 | 없음 | 불가 |
| 일일 보고서 | 날짜, 저장 버튼 | 저장 버튼을 누르면 `.md` 파일 | 불가 |
| AI 에이전트 | 질문 또는 추천 질문 선택 | 없음 | 불가 |

## 7. PRD에서 그대로 가져온 조건

- 화면은 하나이며 왼쪽에 데이터, 오른쪽에 AI 대화를 둡니다.
- 이상한 날 목록은 상위 8일을 이상 점수가 큰 순서로 보여 줍니다.
- 보고서는 화면의 버튼으로 `.md` 파일로 저장합니다.
- 첫 버전은 내 컴퓨터에서만 시연합니다.

## 8. 이 문서에서 다루지 않는 내용

PRD의 제외 기능은 여기서도 만들지 않습니다. 실시간 설비 연결, 기계 제어, 전기요금 계산, 기계별 원인 확정, 로그인, 대화 기록 저장, 다른 공장 데이터 업로드, 온라인 공개가 해당합니다.

## 9. 확인 필요 목록

남은 확인 필요 항목은 없습니다.
