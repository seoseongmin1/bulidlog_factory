# 제작 주문서 (PRD)

> **PRD란?** 무엇을, 누구를 위해, 어디까지 만들지 적은 제작 주문서입니다. 만드는 사람은 이 문서를 보고 작업하고, 완성 여부도 이 문서로 판단합니다.

| 항목 | 내용 |
|---|---|
| 서비스 이름 | 공장 에너지 에이전트 |
| 기준 문서 | [mvp.md](mvp.md) |
| 한 줄 소개 | 공장의 전기 사용 기록을 AI에게 말로 물어보면, AI가 직접 분석해서 그래프와 함께 쉽게 설명해 주는 앱 |
| 만드는 목적 | 포트폴리오와 공모전 출품 |
| 만드는 방식 | 서버는 FastAPI, 화면은 React, 전력 데이터는 Supabase 데이터베이스에 보관합니다. 자동 테스트에는 SQLite를 씁니다. |

## 1. 누가 사용하나요?

| 사용자 | 하려는 일 |
|---|---|
| 공장의 에너지 담당자, 생산관리자 | 전기 사용 현황을 확인하고 보고합니다. |
| 공모전 심사위원, 채용 담당자 | 시연을 보고 이 프로젝트를 평가합니다. 첫 버전의 1차 관람객입니다. |

첫 버전은 실제 공장에 납품하는 제품이 아닙니다.

## 2. 어떤 불편을 해결하나요?

| 지금의 불편 | 서비스가 돕는 방법 |
|---|---|
| 15분마다 쌓인 기록이 1년에 3만 5천 줄이 넘어 읽기 어렵습니다. | 숫자 카드와 그래프로 한눈에 보여 줍니다. |
| 쉬는 날 전기를 많이 써도 표만 봐서는 눈에 띄지 않습니다. | 평소와 다른 날을 자동으로 찾아 줍니다. |
| 숫자를 모으고 계산해서 보고서를 만드는 데 손이 많이 갑니다. | 날짜만 고르면 일일 보고서를 만들어 줍니다. |
| 궁금한 내용을 확인하려면 직접 데이터를 찾고 계산해야 합니다. | 평소 말투로 물으면 AI가 분석해서 설명합니다. |

목표는 담당자가 **숫자를 찾는 시간을 줄이고 무엇을 할지 판단하는 데 집중**하게 하는 것입니다.

## 3. 사용하는 데이터

대우스틸 광양 공장의 2018년 1년 치 전력 측정 데이터를 사용합니다.

| 항목 | 내용 |
|---|---|
| 측정 간격 | 15분마다 1번 |
| 데이터 양 | 35,040건 |
| 들어 있는 정보 | 전기 사용량, 역률, 이산화탄소 배출량, 부하 수준 |
| 없는 정보 | 기계별 사용량, 생산량, 제품 종류, 날씨, 전기요금 |
| 공개 출처 | UCI 머신러닝 저장소 (출처 표기 필요) |

원본은 매일 마지막 15분(23:45~24:00)을 그날의 `00:00`으로 기록합니다. 밤 기록이 새벽으로 잘못 옮겨 가지 않도록, 파일의 줄 순서를 기준으로 시간을 다시 계산해서 사용합니다. 이 보정은 데이터를 데이터베이스에 넣는 단계에서 한 번 적용합니다.

### 데이터 보관 방식

- 원본 전력 데이터 35,040건을 데이터베이스에 한 번 넣어 두고, 앱은 읽기만 합니다.
- 사용자의 질문, 대화, 보고서, 접속 정보는 데이터베이스에 저장하지 않습니다. 이는 로그인과 대화 기록 저장을 제외한 PRD의 조건과 같습니다.
- 화면은 데이터베이스에 직접 접속하지 않습니다. 서버만 접속하므로 접속 정보가 화면에 노출되지 않습니다.
- 화면과 서버는 내 컴퓨터에서 실행하고, 데이터만 인터넷의 Supabase에 둡니다. 그래서 시연할 때 인터넷 연결이 필요합니다.
- 개발 중과 자동 테스트에서는 내 컴퓨터의 SQLite 파일을 데이터베이스로 씁니다. 시연할 때 Supabase로 바꿉니다.

## 4. 기능별로 할 수 있는 일

### 기능 1. 한눈에 보는 대시보드

사용자는 다음을 할 수 있습니다.

- 1년 치 전기 사용량을 숫자 카드로 확인합니다.
- 월별, 시간대별, 날짜별 그래프로 언제 전기를 많이 썼는지 확인합니다.

### 기능 2. 이상한 날 찾기

사용자는 다음을 할 수 있습니다.

- 유난히 많이 쓰거나 적게 쓴 날을 확인합니다.
- 추석처럼 공휴일이라 사용량이 적은 날은 공휴일 이름과 함께 확인합니다.
- 목록의 날짜를 눌러 그날의 일일 보고서를 엽니다.

비교 기준은 앞뒤 4주 동안의 비슷한 날입니다. 평일은 평일끼리, 주말은 주말끼리 비교합니다.

목록에는 탐지된 날 중 상위 8일을 평소와 다른 정도가 큰 순서로 보여 줍니다. 이 순서는 단순한 증가율이 아니라, 평소의 들쭉날쭉한 정도까지 고려한 이상 점수로 정합니다.

### 기능 3. 일일 보고서 자동 생성

사용자는 다음을 할 수 있습니다.

- 날짜를 고릅니다.
- 그날의 사용량, 평소 대비 차이, 최대 사용 시각 등을 표로 확인합니다.
- 화면의 버튼을 눌러 보고서를 `.md` 파일로 저장합니다.

### 기능 4. 말로 묻는 AI 에이전트

사용자는 다음을 할 수 있습니다.

- "1월과 9월을 비교해줘"처럼 평소 말투로 질문합니다.
- AI가 필요한 분석을 골라 실행한 결과를 그래프와 설명으로 확인합니다.

처음 쓰는 사람을 위해 추천 질문 4개를 제공합니다.

- 12월 16일 일요일에 왜 전력을 많이 썼을까?
- 역률이 낮은 시간대와 개선 방향을 알려줘
- 1월과 9월을 비교해줘
- 최대 수요전력을 10% 낮추면 어떻게 돼?

AI는 다음과 같은 순서로 답합니다.

1. 사용자의 질문을 읽고 필요한 분석을 판단합니다.
2. 분석 프로그램이 데이터로 숫자를 계산합니다.
3. 앱이 계산 결과로 그래프를 그립니다.
4. AI가 결과의 의미를 쉬운 말로 설명합니다.

### 모든 기능에 적용하는 약속

| 약속 | 내용 |
|---|---|
| 숫자는 프로그램이 계산합니다. | AI가 숫자를 지어내지 않도록 계산은 분석 프로그램이 맡고, 그래프도 계산 결과로만 그립니다. |
| 사실과 추측을 나눕니다. | 기계별 데이터가 없어 정확한 원인은 단정하지 않습니다. 추측은 "가능성"으로 표시하고 확인 방법을 제안합니다. |
| 모르는 금액은 말하지 않습니다. | 전기요금 정보가 없으므로 원화 금액을 제시하지 않습니다. |
| 읽고 분석만 합니다. | AI는 공장 기계를 제어하지 않습니다. |

## 5. 필요한 화면

| 화면 요소 | 사용자가 보는 내용 | 관련 기능 |
|---|---|---|
| 대시보드 | 숫자 카드, 월별·시간대별·날짜별 그래프 | 기능 1 |
| 이상한 날 목록 | 평소와 가장 크게 다른 8일, 많음과 적음, 공휴일 이름 | 기능 2 |
| 일일 보고서 | 날짜 선택, 보고서 표, `.md` 파일 저장 버튼 | 기능 3 |
| AI 대화 | 질문 입력, 분석 진행 상황, 그래프, 답변 | 기능 4 |

위 내용을 모두 한 화면에 배치합니다. 왼쪽에는 대시보드, 이상한 날 목록, 일일 보고서를 두고, 오른쪽에는 AI 대화를 둡니다. 사용자는 화면을 옮기지 않고 데이터를 보면서 질문할 수 있습니다.

## 6. 첫 버전 완성 기준

아래를 모두 만족하면 첫 버전이 완성된 것입니다.

### 기능 완성

- [ ] 대시보드에서 1년 치 사용량과 월별, 시간대별, 날짜별 그래프를 볼 수 있다.
- [ ] 평소와 다른 날을 확인할 수 있고, 공휴일 이름이 함께 표시된다.
- [ ] 날짜를 고르면 일일 보고서가 표로 나오고, 화면의 버튼으로 `.md` 파일을 저장할 수 있다.
- [ ] 실제 AI에게 평소 말투로 질문하고 그래프와 함께 답을 받을 수 있다.

### 품질 확인

- [ ] 추천 질문 4개에 AI가 실제 데이터를 기반으로 답한다.
- [ ] AI가 말한 숫자가 분석 프로그램의 계산 결과와 일치한다.
- [ ] AI가 원인을 단정하지 않고 사실과 가능성을 구분한다.
- [ ] 처음 보는 사람이 설명 없이 3분 안에 질문하고 결과를 이해한다.
- [ ] 공모전 발표에서 3분 안에 문제, 해결 방법, 발견한 내용을 시연할 수 있다.

## 7. 이번에 만들지 않는 기능

| 만들지 않는 기능 | 이유 |
|---|---|
| 공장 설비와 실시간 연결 | 실제 공장이 없고, 공개된 과거 데이터로 먼저 검증합니다. |
| AI가 기계를 직접 제어 | 잘못되면 위험하므로 읽고 분석하는 일만 합니다. |
| 전기요금 계산 | 요금 데이터가 없어 금액을 만들어 낼 수 없습니다. |
| 기계별 원인 확정 | 기계별 데이터가 없습니다. |
| 로그인, 대화 기록 저장 | 내 컴퓨터에서 시연하는 용도라 지금은 필요 없습니다. |
| 다른 공장 데이터 업로드 | 한 공장의 데이터로 핵심 기능부터 검증합니다. |
| 온라인 공개 | 첫 버전은 내 컴퓨터에서만 시연합니다. 공개하면 다른 사람이 내 API 키로 요금을 쓸 수 있습니다. |
